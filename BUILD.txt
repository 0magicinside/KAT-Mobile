KAT MOBILE RX 0.8.0-en — BUILD (Windows)

1. Install JDK 17, Android SDK platform android-36, build-tools and platform-tools.
   Set JAVA_HOME and ANDROID_HOME if they are not detected automatically.
2. Install Rust/rustup, then:
     rustup target add aarch64-linux-android i686-linux-android
   The current Windows GNU host configuration references
   C:/msys64/ucrt64/bin/gcc.exe. Install MSYS2 UCRT64 GCC there or adjust
   native/.cargo/config.toml for your host compiler.
3. Provide Android NDK r27c (27.2.12479018) under:
     .tools/android-ndk-r27c/
   clang.exe must exist in toolchains/llvm/prebuilt/windows-x86_64/bin/.
   On the original machine .tools links to the existing local installation.
4. From this project folder:
     powershell -ExecutionPolicy Bypass -File .\Build.ps1
   Output: dist/KAT-Mobile-RX.apk

The prepared Rust receive core is included in native/; no desktop checkout is
required for a normal build. tools/prepare_rx_core.py is a regeneration utility
and requires the supplied sibling KAT-1.29.0 tree. Do not regenerate routinely.
Gradle/Maven/Cargo dependencies need internet access on a fresh machine.

The release APK is ARM64 and is currently signed with the local Android debug
key. A different machine's key cannot update an installed app signed with the
original key. No signing key is included in shareable source packages.

Optional device tests (separate .qa application):
     .\Build.ps1 -DeviceTests -Serial YOUR_SERIAL
Optional main application install (preserves data when signed with same key):
     .\Build.ps1 -Install -Serial YOUR_SERIAL

Host Rust integration tests additionally require the Windows GNU/MSYS2 compiler
referenced by native/.cargo/config.toml. Run JVM tests first for the FOB fixture.
